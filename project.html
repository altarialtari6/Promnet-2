Project 1: Website Saung Hibar

Ini merupakan project UAS Pengantar PSTI Semester 1, saya dan kelompok (kelompok SABAR) membuat sebuah website untuk mempromosikan salah satu pariwisata yang ada di purwakarta, yaitu Saung Hibar sebuah tempat pariwisata untuk camping. Dan saya bertugas untuk membuat rancangan awal dari tampilan home website itu sendiri.
(Laman website Saung Hibar disini)


Project 2: Maps roblox yang published

Ini merupakan project UAS Literasi Digital Semester 1, saya dan kelompok ditugaskan membuat sebuah artikel yang dimana artikel yang kami pilih harus menghasilkan output berupa pembuatan maps roblox yang harus di published agar dapat digunakan oleh banyak user di app roblox itu sendiri.


Project 3: Game Design

Ini merupakan project Semester 2 Analisis dan Perancangan Sistem Informasi, dimana dalam project ini dibagi kembali menjadi beberapa tim, dan saya mendapatkan bagian di tim perancangan Level dan Design Game itu sendiri.


Project 4: Rancangan Basis Data

Ini merupakan project UAS Basis Data Semester 2, saya dan kelompok membuat sebuah Rancangan Sistem Basis Data, yaitu Sistem Informasi Manajemen Bengkel, dengan menggunakan HTML dan MySql itu sendiri.


Project 5: Personal Website

Ini merupakan website yang berisikan biodata diri dan project an yang sudah dan sedang saya lakukan, untuk memenuhi tugas mata kuliah Pemrograman Internet di semester 3 dengan menggunakan HTML dan VS Code.
